# Harborview beta downloads

This repository hosts Harborview React/Tauri application packages, update signatures, release notes and the update feed. Source code is maintained in a separate private repository.

No beta application release has been published yet. Initial local-beta support targets macOS 14 or newer on Apple Silicon. Windows and Intel packages are not currently offered here.

The beta uses ad-hoc macOS application signing and cryptographically signed Tauri update packages. Downloaded applications may need approval in macOS Privacy & Security. Account activation remains invitation-only; download URLs are public.

When available, download packages from Releases. Extract the application archive and move the app into Applications. Subsequent releases can be discovered through the app's update controls.
